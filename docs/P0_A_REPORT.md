## 검증 결과

- SQLite: `pytest -q` **13 passed**.
- 별도의 임시 로컬 MySQL **9.6.0**: 동일 테스트 **13 passed**. Docker 엔진 미실행으로 Compose의 MySQL 8.4 이미지는 직접 구동하지 못했다.
- 실제 Uvicorn HTTP 서버 + MySQL + `scripts/demo.py`: **후보 3개, 기상 3종×3회 = 27개 실험**, 저장·조회·비교·JSON export 성공.
- 스냅샷으로 27개 실험 재계산: 원본 지표와 **전부 일치**, 입력 SHA256 검증 통과.
- 예제 후보 모두 선분 기하 검사 통과. 장애물/금지영역까지 최소 이격은 **10.607m**, 요구 총 여유 5m 초과.
- 강풍에서는 세 후보 모두 지상속도 부족으로 실패하여 **추천 없음**. 약풍/중풍에서는 모두 통과하고 후보 1 추천.
- 테스트 도구의 Starlette/httpx 폐기 예정 경고 1건이 있으며 테스트 실패는 없다.

## 남은 항목 및 완료 판단

A의 P0 백엔드 기능은 합성 환경에서 실행·검증했다. 다음 외부 자료 및 공동 작업이 남아 있어 **전체 P0 또는 계획서의 모든 체크리스트 완료로 보고하지 않는다**.

- 기존 메이커톤 코드/데이터/라이선스가 없어 기존 데모 이관은 수행하지 못했다. 새 합성 환경으로 대체 구현했다.
- 실제 도시 및 과거 관측 기상 자료는 제공되지 않았다. 기본 기상 3종은 모두 합성이며 과거 관측을 등록할 스키마/API만 구현했다.
- Cesium UI, 지도 클릭, 위험/이격 영역 렌더링, UI→API E2E는 B 담당 후속 작업이다. API 연동 계약은 `docs/API_CONTRACT.md`에 있다.
- 점검 커버리지는 방문점 반경, 재난 커버리지는 지정 타깃 방문률이다. 실제 시야 차폐나 구역 면적 커버리지 모델은 포함하지 않는다.
- 대체 경로는 유한 탐색 예산의 휴리스틱이므로 가능한 모든 경로 수나 항상 3~5개를 보장하지 않는다. 부족하면 실제 수와 사유를 반환한다.
- 위험/기상/에너지 모델은 실측 검증되지 않은 비교용 모델이다. 실제 비행 성능·안전 인증이나 P1 AI 개선을 주장하지 않는다.
- MySQL 8.4 Docker 직접 검증, B와의 공동 리뷰, 기존 데이터 이관은 완료되지 않았다.

## 실행·인계

`README.md`의 명령으로 서버와 테스트를 실행한다. `scripts/demo.py`는 실행 중인 서버에 요청해 재검증용 JSON을 생성한다. 기본 데이터 ID는 `demo-city`, `weak`, `moderate`, `strong`이다. 자동 검증에 사용한 임시 서버/DB는 종료했다.
