# F00 원본 코드 이관 기록

- 원본 저장소: https://github.com/kjyook/makerthon_2026
- 확인한 원본 커밋: `38253ea` (`Initial commit: Flask + CesiumJS project setup for UAM Risk Visualization`)
- 이관 범위: 3D mock 복셀, 위험도 휴리스틱, 26방향 A*, 가중치 산정 로직 및 CesiumJS 데모 UI. Flask API를 FastAPI로 옮겼습니다.
- 권한: 요청자가 원본 코드의 이관 권한을 확인했습니다.
- 라이선스: 확인 시 원본 저장소에 LICENSE 파일이나 명시적 라이선스가 없었습니다. 별도 라이선스를 임의로 부여하지 않았습니다. 원본 코드의 재사용은 확인된 권한에 근거하며, 이후 외부 배포 조건은 저작권자와 별도로 확인해야 합니다.
- 데이터: 원본에는 건물/기상 데이터 파일이 없었습니다. README의 V-World 언급은 향후 연동 예정 설명이며, V-World 데이터를 이관하거나 다운로드하지 않았습니다. 현재 mock 건물은 코드에 정의된 데모 데이터입니다. 실제 데이터 도입 시 출처, 이용 조건 및 재배포 가능 여부를 별도로 확인해야 합니다.
- 외부 자산: CesiumJS는 기존과 같이 CDN 참조로 사용하며 소스 파일은 복제하지 않았습니다. Cesium Ion 토큰은 선택 사항이며 공개 클라이언트 토큰만 사용해야 합니다.
- 좌표/단위: 원본 UI의 위경도 증분 및 높이 증분은 복셀 크기와 일치하지 않았습니다. 데모 표시를 위해 10 m 복셀 중심을 로컬 ENU로 계산하고 WGS84 원점 `(126.62°E, 37.37°N, 0 m)`에 변환합니다. 원점은 실측 데이터와 정합된 값이 아닙니다.
